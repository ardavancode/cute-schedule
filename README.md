# My Next.js App

This is a basic Next.js application with the following features:

- App Router
- Tailwind CSS for styling
- Basic pages (Home and About)
- API routes

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- **Home Page**: The main landing page with links to other pages and API routes
- **About Page**: A simple about page
- **API Route**: A basic API endpoint at `/api/hello`
